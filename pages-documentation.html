Introduction

Irvan Maulana Updated 2 hrs ago Stable

Selamat datang di dokumentasi resmi Daily Admin. Ini adalah framework UI/UX modern yang dibangun di atas CSS murni dan Vanilla JS, dirancang untuk kecepatan dan kemudahan penggunaan.

Info Penting: Dokumentasi ini menggunakan struktur kode asli Anda (CSS Core, Components, dll). Tidak ada library pihak ketiga yang berat.

Installation

Untuk memulai proyek baru, cukup salin folder assets ke dalam root direktori proyek Anda dan pautkan file CSS utama.

HTML
<!-- Core Styles --> <link rel="stylesheet" href="assets/css/core.css" /> <link rel="stylesheet" href="assets/css/layout.css" /> <link rel="stylesheet" href="assets/css/components.css" /> <!-- Scripts --> <script src="assets/js/core.js"></script>

Folder Structure

Struktur folder direkomendasikan agar semua aset terorganisir dengan rapi.

Berisi semua file statis: css/, js/, img/, dan webfonts/.

Key Features

Template ini dilengkapi dengan berbagai fitur premium yang siap pakai:

  • Dark Mode Native: Menggunakan CSS Variables var(--bg-body).
  • Pure CSS Tree: Navigasi folder tanpa JS berat.
  • Glassmorphism: Utilitas .glass untuk efek modern.
  • Responsive: Grid system 12 kolom yang solid.
