List Group

Komponen daftar yang fleksibel untuk menampilkan serangkaian konten. Mendukung interaksi hover slide, state aktif, dan konten kompleks.

Dashboard List Group
Panduan Penggunaan
  • Gunakan wrapper .list-group untuk membungkus item.
  • Gunakan class .list-group-item pada setiap elemen anak (bisa berupa <a>, <button>, atau <div>).
  • Tambahkan class .active untuk menandai item yang dipilih (efek border kiri & gradient).
  • Gunakan Utility Classes (flexbox) untuk mengatur layout di dalam item.
