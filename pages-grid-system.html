Grid System

Dokumentasi sistem tata letak (layout) menggunakan CSS Grid untuk struktur halaman utama dan Flexbox Utilities untuk komponen internal.

Dashboard Grid System
Panduan Singkat

Gunakan .content-grid (Layout CSS) untuk membagi halaman utama (Main Dashboard).
Gunakan .row & .col-* (Utilities CSS) untuk membagi isi di dalam Card atau Form.

1. Page Layout (CSS Grid)

12-Column Grid Wrapper

Gunakan class .content-grid sebagai pembungkus utama. Grid ini memiliki 12 kolom dan responsive otomatis (menumpuk di mobile).
